What is UPID?
UPID (UPI ID) is used to receive payments from users when they recharge coins. Only one UPID can be active at a time. Use "Update" to change existing UPID.
Format: username@bank or mobilenumber@upi
📖 How UPID Works
1️⃣
Set Your UPID
Add your UPI ID from this panel. Only one can be active.
2️⃣
User Recharges
App shows your UPID to users during coin recharge flow.
3️⃣
Payment Received
User pays via any UPI app. Admin verifies and credits coins.
🔄
Update Anytime
Change UPID at any time. Old one is immediately replaced.
